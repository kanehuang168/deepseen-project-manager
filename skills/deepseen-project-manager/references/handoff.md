# 最小交接与恢复记录

- 用户目标与完成标准；范围及不做的事。
- 当前版本/输入、已授权动作与预算；费用上限不跨轮沿用。
- 已有产物、真实任务编号、有效证据及验证环境；没执行的步骤写清。
- 未决问题、负责人或当前宿主、下一步与依赖；只能用户亲自完成的动作单列。
- 返修归属、停止/回滚条件；成功产物继续保留。

恢复示例：方案已确认，供应商已受理但未返回结果，应继续查询原任务。不要再生成一遍，也不要把进度查询超时写成生成失败。现有报告若过期，标明其数据时间，不拿旧报告冒充今天。

任务记录中不放密钥、临时签名、其他客户聊天或无关个人信息。宿主无持久调度能力时留可接手记录，不声称后台会继续运行。
