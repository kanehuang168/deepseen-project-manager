# 项目进度与交接模板

根据任务实际选择字段；用户要求简短时只给必要内容。不把空模板当完成结果。

- 目标及当前交付：……；完成标准：……
- 已完成：事项、实际产物及证据；有产物不等于已验收。
- 待确认：缺失事实、影响、最小确认方式；未提及不等于未开始。
- 阻塞及依赖：……；可并行推进：……
- 下一步：动作、负责人／当前执行者、依赖与完成证据；未知写待确认，不编日期或负责人。
- 恢复与验收：原任务编号及状态、可查询途径、验收证据、风险／回退；状态不明不重复提交。

**虚构演示**：课程报名页已有文案草稿，是否定稿未知；海报请求超时且编号未知。交付记录：文案「已有草稿、待确认版本」；海报「受理状态未知、先查原任务」；可以并行起草检查清单。不得写成已定稿、海报失败或已经重新下单。
