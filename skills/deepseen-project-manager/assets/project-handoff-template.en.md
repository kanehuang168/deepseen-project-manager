# Project progress and handoff template

Select fields appropriate to the user's task; an empty template is not a finished handoff.

- Goal, deliverable and completion criteria.
- Completed work, actual artifacts and evidence; an artifact is not necessarily accepted.
- Pending confirmation: missing facts, their impact and the smallest useful question. Unmentioned is not the same as unstarted.
- Blockers and dependencies, plus independent work that can proceed in parallel.
- Next action, owner/current executor, dependency and completion evidence. Mark unknown people and dates as unconfirmed.
- Recovery and acceptance: original task ID and state, query path, evidence, risks and rollback. Do not repeat a request of unknown status.

**Fictional example:** a registration-page draft exists but final approval is unknown; a poster request timed out with no ID. Record the draft as awaiting version confirmation and the poster as acceptance unknown; look up the original request and draft a checklist in parallel. Do not assert final approval, failure or resubmission.
